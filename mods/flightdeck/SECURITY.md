# Security

Flightdeck observes your session and keeps derived fields in session state. It never keeps your prompts: a typed turn is logged as its length alone, and to match a turn to its source it holds a hash of each prompt in memory, never the text. Of a subagent's answer it keeps nothing, except one line of an architect's report, masked and cut to 160 characters. Every text it keeps goes through `scrub()` in `hooks/hygiene.ts`, which masks secrets and cuts the text to a fixed cap. A field derived from a masked text goes through it again whenever the derivation changed the text. "What it keeps" in the README lists each field and the test that checks it. `/flightdeck audit` lists what is held at any moment. In passive use, Flightdeck makes no network requests, runs no processes, and reads or writes no files.

`scrub()` masks by pattern. A secret with no key name and no known token shape can survive in the fields that keep words: an architect's advice line, an agent's description, name and type, a consult's agent type, an architect roster entry, and a tool detail's program word, path segments or host. "What it does not catch" in the README lists the misses its tests pin.

Managed activity can start a `pi-bolt` process, and only after `/flightdeck managed on`. The prompt is one argument of that process and may be visible to other local processes. The child inherits the host environment and may send the prompt to its model provider. Claude's native tool permission checks do not wrap the child. Do not enter secrets. The session ID and event type are scrubbed and kept in module memory, not in session state, and both are dropped on managed-off, reset, clear, resume, and unload. The answer, tool events, paths, and raw stream are discarded; a partial event line past 8 KiB is dropped instead of held.

If you find a way it could leak data, for example a credential format that `scrub()` misses or a field that skips it, report it privately through GitHub's **Security → Report a vulnerability** on [noomz/noomz-claude-skills](https://github.com/noomz/noomz-claude-skills) rather than in a public issue. A fix to `scrub()` lands in `mods/pinboard/hooks/hygiene.ts` and `mods/flightdeck/hooks/hygiene.ts` together, with a case in `tests/hygiene.test.ts`.
